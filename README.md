# 全球顶级 ETF 看板

交互式 ETF 看板，覆盖 **27 只全球旗舰 ETF、10 个资产大类**（美股宽基 / 纳斯达克100 / 科技 / 半导体 / 全球股市 / 新兴市场 / 美国小盘 / 红利 / 债券 / 黄金）。

## 内容

- **ETF 介绍**：27 只 ETF 的管理人、成立日、跟踪指数、规模、费率、持仓数与定位，可筛选、搜索、排序
- **收益表现**：2016–2026 逐年总收益热力图、10 年 CAGR 排行、多周期回报与最大回撤、$100 累计增长曲线（对数坐标）
- **成分结构**：前十大持仓、前3/前10 集中度、英伟达暴露对比
- **估值温度计**：CAPE / 前瞻PE / 股息率 / PEG 温度计、静态 vs 前瞻 PE、盈利收益率 vs 无风险利率、逐 ETF 估值映射

## 技术说明

单文件静态页面，全部为内联 CSS / JS + 原生 SVG，**不依赖任何外部 CDN 或图表库**，可离线打开。

## 数据来源与口径

数据口径日 **2026-09-30**，来源为用户提供的两份对比表 + 公开披露与联网补充。

> 重要口径提示：表中「10年CAGR / 周期回报」为**滚动窗口口径**（约 2016 年年中至 2026 年年中、含 2026 年至今），与逐历年的日历年口径不同。规模、估值随市波动。
